# Changelog

## 0.1.0-beta.3

- Include this adapter repository name and build version in PAM STS User-Agent headers.
- Defer Alibaba Cloud credentials loading until client creation.
- Use Core SDK and PAM SDK 0.1.0-beta.3.

- Support renewable credentials for Alibaba Cloud OpenAPI, OSS, and SLS.
- Improve credential expiry checks, refresh behavior, and resource cleanup.
- Provide CommonJS/ESM packages, TypeScript declarations, and English/Chinese usage documentation.
